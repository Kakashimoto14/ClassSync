## Role capability matrix (source-level)

| Capability                        | Student                                          | Teacher                      | Administrator                                                                       |
| --------------------------------- | ------------------------------------------------ | ---------------------------- | ----------------------------------------------------------------------------------- |
| Own published schedule / calendar | Read own published projection                    | Read own assigned projection | Read period/publication state                                                       |
| Academic records / roster         | No                                               | No                           | Manage period-scoped academic inputs, subject to current membership and owner scope |
| Generate / validate / draft       | No                                               | No                           | Yes, guarded by readiness and current authorization                                 |
| Review / publish / rollback       | No                                               | No                           | Publication APIs enforce privileged server-side authorization                       |
| Classroom request                 | Student-specific connected route not established | Submit request               | Review/decide/fulfill                                                               |
| Room directory                    | Read-only, whitelisted published data            | Read-only                    | Manage academic resource metadata where routes allow                                |
| Announcements                     | Audience-scoped read                             | Audience-scoped read         | Manage within server-authorized scope                                               |
| Profile / account                 | Own profile                                      | Own profile                  | Own profile; account administration is separately privileged                        |
| Preview role                      | Demo only; grants no institutional authority     | Demo only                    | Demo only                                                                           |

The matrix must be confirmed against `route-config.ts`, `RouteGuard.tsx`, Gateway and downstream authorization on each endpoint; frontend visibility is not permission enforcement.
