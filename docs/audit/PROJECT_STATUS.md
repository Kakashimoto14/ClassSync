## Overview and architecture

ClassSync is a university academic-data and classroom scheduling application with Student, Teacher, and Administrator experiences. The connected architecture is React 19 / TypeScript / Vite 6, a Firebase Authentication client, a FastAPI Gateway plus Academic and Scheduling services, shared Pydantic contracts, SQLAlchemy/Alembic persistence, PostgreSQL adapters with FORCE RLS, and OR-Tools CP-SAT followed by a solver-independent validator. SQLite remains for local sandbox/demo and selected fixtures. Notification is currently a health-only service. See `docs/architecture.md`, `docs/security.md`, and `docs/autonomy/STATUS.md`.

The repository contains 16 migration revisions (0001–0016), not only the first 11 requested in the audit prompt. Revisions 0012–0016 add curriculum identity, synthetic review isolation, account onboarding, classroom requests, and announcements. Existing migration history must be reviewed as a chain; new migration numbering must continue from the actual head, never reuse 0012.

The requested product direction is clean and restrained, with purposeful minimal icons and accessible smooth transitions; motion is an evaluated enhancement, not a launch dependency.
